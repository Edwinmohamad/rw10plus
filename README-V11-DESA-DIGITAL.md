# RW10+ v11 — Cicadas Digital

Branding portal diubah menjadi **Cicadas Digital** dengan fokus **Desa Digital** untuk RW10 Desa Cicadas, Kecamatan Gunung Putri, Kabupaten Bogor.

## Perubahan
- Menghapus branding Pabuaran dari UI web publik, portal internal, CMS, PWA, dan label APK.
- Identitas utama: **Cicadas Digital**; cakupan operasional saat ini tetap RW10 / RT01–RT04.
- Menampilkan Lambang Kabupaten Bogor sebagai identitas wilayah pada web publik, CMS, dan portal/app internal. Sumber utama: Wikimedia Commons, dengan sumber/author Pemerintah Kabupaten Bogor dan dasar Perda lambang daerah. Jika perangkat tidak dapat mengakses gambar daring, UI memakai fallback lokal agar layout tidak rusak.
- Tema visual hijau-biru civic-tech, tetap minimal dan tidak mengubah kontrak API/backend.
- Android launcher label menjadi **Cicadas Digital**.

## Catatan penting
Penggunaan lambang Kabupaten Bogor pada UI dimaksudkan sebagai penanda wilayah. Portal ini tidak otomatis menjadi situs resmi Pemerintah Desa/Pemerintah Kabupaten tanpa penetapan resmi dari instansi terkait.
